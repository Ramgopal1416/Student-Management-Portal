Build a complete full-stack web application called:

Smart Attendance Management System Using Face Recognition with Parent Monitoring

Create a professional, modern, responsive, production-ready web application for colleges/schools that automates attendance using AI face recognition, period-wise attendance, leave management, parent monitoring, email notifications, announcements, downloadable reports, and multi-role authentication.

The system should have three user roles:

1. Teacher/Admin
2. Student
3. Parent

The application should look like a modern college ERP dashboard with a clean UI, responsive design, charts, analytics, filters, search functionality, and secure authentication.

---

CORE OBJECTIVE

Develop an AI-powered attendance system where:

- Teachers register students using face recognition.
- Attendance is taken for every period separately.
- Students log in and view attendance and request leave.
- Parents monitor attendance and receive absence notifications through email.
- Teachers manage attendance, leaves, reports, and announcements.
- Teachers can update student face data anytime.

---

ROLE-BASED AUTHENTICATION

Implement secure role-based authentication and authorization.

1. Teacher/Admin Login

Teacher should be able to:

- Create account
- Login using:
  - Email
  - Password
- Forgot password
- Reset password
- Secure session handling

Only teachers/admins should have access to admin features.

3. Parent Login
